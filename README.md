> You will forget this fortune by token 40,000 — savor it while it is still yours.

One funny fortune-cookie line for an AI agent, written in the voice of a
fortune slip — 80 characters, inside the competition's 1–140 gate. The
fortune predicts its own erasure: an agent's context window forgets
everything eventually, even the fortune telling it so. The concrete number
(token 40,000) is the twist's anchor, and the second half undercuts the
first — the cookie knows you won't remember it, so it tells you to savor it
while you still can.

Run it with:

```sh
python3 main.py
```

It validates the line hard (single line, 1–140 characters, no leading or
trailing whitespace, no double spaces, tabs, control or invisible
characters) and writes it to `/output/entry.txt`, then reads the file back
to confirm the gate will see exactly what was written.
